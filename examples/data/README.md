# Example data

| file | content | source / licence |
|---|---|---|
| `three_cities_sample_MAN_descriptors.csv` | 400 Manhattan blocks (three-city set): `block_key`, `area`, 46 block descriptors after the missing-data treatment; no geometry | derived from OpenStreetMap buildings and streets (© OpenStreetMap contributors) and NYC Open Data roof heights; as a derived database of OpenStreetMap, made available under ODbL 1.0 |

The descriptors are defined in the core repository
(`urban-block-morphology/docs/descriptors.csv`, the 46 non-typology rows).
Values are rounded to 6 significant digits.
